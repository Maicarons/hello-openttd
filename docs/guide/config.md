# 配置管理

OpenTTD 的行为几乎都由 `openttd.cfg`（INI 风格）控制。hello-openttd 提供配置方案管理与图形化编辑器。

## 配置方案

配置方案在**安装版本时**选定，也可在版本详情中随时切换：

- **独立配置**：每个版本目录内有一份 `openttd.cfg`（以及 `save/`、`content_download/` 等），隔离最彻底。
- **共享配置**：启动器以 `-c` 参数指向全局配置文件，并通过目录链接共享模组与存档目录。

切换方案时启动器会引导你**迁移或复制**现有配置与数据，不会静默丢弃。

## 图形化编辑器

**配置页**左侧是分区（section）树，右侧是该分区的键值表单：

- **类型化控件**：布尔值用开关、枚举用下拉框、数值带范围校验、路径/颜色有专门控件。
- **双语说明**：每个键都有中文/英文的名称与解释（鼠标悬停或右侧面板）。
- **搜索**：按键名或说明搜索，快速定位（比如搜"自动保存"）。
- **原始视图**：直接编辑文本，适合高级用户；与表单视图实时同步。
- **修改追踪**：未保存的改动以标记显示；保存前统一校验（类型、范围、非法字符）。

编辑器不会发明配置：它基于内置的**键目录**（key catalog）渲染表单，未收录的键在原始视图中编辑，不会丢失。

## 保存与备份

- 保存时启动器自动在版本目录（或共享目录）生成 `openttd.cfg.bak-YYYYMMDDHHmmss`。
- 配置页可查看/恢复最近 10 份备份。
- **安全提示**：`private.cfg`（含密码）与 `secrets.cfg` 中的敏感值在编辑器中**脱敏显示**且默认禁止导出。

## 常用配置项速查

| 分区 | 键 | 作用 |
|------|----|------|
| misc | `language` | 界面语言 |
| gui | `autosave` | 自动保存间隔（off/3/6/12 个月游戏时间） |
| gui | `autosave_on_exit` | 退出时自动保存 |
| misc | `currency` | 货币单位 |
| game_creation | `year` | 起始年份 |
| game_creation | `map_x` / `map_y` | 地图大小（2^n） |
| difficulty | `max_no_competitors` | AI 对手数量（0-14） |
| vehicle | `max_trains` 等 | 车辆上限 |
| network | `client_name` | 联机昵称 |
| network | `server_name` | 服务器名称（做主机时） |

> 键名与取值以所装 OpenTTD 版本为准；不同版本（尤其 JGRPP）会有额外键，未收录键请用原始视图编辑。

## 高级

- 配置文件中的**未知分区/键**会被原样保留（注释与顺序也保留）——解析器是行保留式的，详见[配置解析器设计](/dev/cfg-parser)。
- 需要完全重置：删除 `openttd.cfg` 后由游戏重新生成，或使用配置页的"恢复默认"。
