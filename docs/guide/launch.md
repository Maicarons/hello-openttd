# 启动器

一切就绪后，启动游戏只差一个按钮。启动页同时承担**参数构建**与**进程监控**。

## 启动方式

| 方式 | 对应参数 | 说明 |
|------|----------|------|
| 新游戏 | `-g` | 生成随机地图开新局 |
| 载入存档 | `-g <save>` | 直接进入指定 `.sav`（可在首页快速选择最近存档） |
| 加入服务器 | `-n host[:port]` | 联机；服务器列表来自 OpenTTD 的 `servers.cfg` 与手动收藏 |
| 专用服务器 | `-D [host:port]` | 无窗口 dedicated 模式，可配置端口与绑定地址 |

其他可选参数（可在启动页折叠面板中设置）：

| 参数 | 作用 |
|------|------|
| `-c <cfg>` | 指定配置文件（共享配置模式自动带上） |
| `-r 1920x1080` | 窗口分辨率 |
| `-v` / `-s` / `-m` | 视频驱动 / 声音驱动 / 音乐驱动 |
| `-d [级别]` | 调试输出（排查问题时用） |
| 自定义 | 任意附加参数，原样附加在末尾 |

> 参数全集以游戏 `openttd --help` 为准；启动器构建的命令行可在启动前**预览确认**。

## 一键启动

- **首页启动台**：默认版本 + 最近存档，点击即玩。
- 启动设置项：
  - 启动后**最小化/退出**启动器（默认仅最小化）
  - 失败时**保留命令行与日志**方便反馈

## 多实例

OpenTTD 支持同时开多个进程，启动器默认**允许多实例**：

- 每次启动生成独立的**运行记录**（开始时间、版本、退出码、日志文件）。
- 共享配置模式下同时开两个实例会提示潜在配置争用（游戏退出时可能互相覆盖部分配置），可选择继续或取消。
- 同一版本在独立配置模式下可放心多开。

## 进程监控

运行中的实例显示在启动页底部：

- **状态**：运行中 / 已退出（含退出码）/ 启动失败
- **实时日志**：游戏 stdout/stderr 写入 `logs/runs/<run-id>.log`，可在线查看与跳转文件
- **结束进程**：先尝试优雅终止，超时后强制结束
- **异常退出提示**：非零退出码时给出日志尾部摘录，方便定位崩溃原因
