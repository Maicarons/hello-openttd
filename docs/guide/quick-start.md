# 快速上手

目标：5 分钟内装好一个 OpenTTD 并开一局游戏。

## 1. 安装第一个版本

1. 打开启动器，进入 **版本管理** 页面。
2. 选择版本源（默认 **OpenTTD 官方**，也可选 **JGRPP** 等），点击 **安装**。
3. 在向导中选择一个稳定版本（如 14.1），确认下载。
4. 启动器自动完成：下载（自动选择最快镜像）→ SHA-256 校验 → 解压 → 写入版本清单。

> 💡 首次安装时需要选择**配置方案**：
> - **独立配置**（推荐）：每个版本有自己的 `openttd.cfg`、存档、模组目录，互不影响。
> - **共享配置**：所有版本共用一套配置与数据，切换版本时如同"换引擎不换车厢"。
> 详见[版本管理](./versions#独立与共享配置)。

## 2. 启动游戏

1. 在 **首页** 或 **版本管理** 中选中刚装好的版本，点击 **▶ 启动**。
2. 游戏窗口弹出后即可游玩。

也可以先在启动器里设定启动方式（在启动页配置）：

- **新游戏** — 直接进入随机地图
- **载入存档** — 选择 `.sav` 文件启动
- **加入服务器** — 填入 `host[:port]` 联机
- **专用服务器** — 无窗口的 dedicated server 模式

## 3. 装几个模组（可选）

1. 进入 **模组中心**，按类型筛选（NewGRF / AI / GameScript / 音轨集 / 场景）。
2. 搜索感兴趣的内容（例如 `UK`、`2CC`、`OpenAVS`），查看详情后点击 **安装**。
3. 启动器将内容安装到该版本 `content_download/` 下对应目录，游戏内即可启用。

> ⚠️ 注意模组与游戏版本的兼容性，详见[模组中心](./mods#兼容性提示)。

## 4. 调整偏好

- **切换语言**：设置 → 语言 → 简体中文 / English。
- **切换主题**：设置 → 主题 → 浅色 / 深色 / 跟随系统。
- **下载慢**：设置 → 下载与镜像 → 添加自定义镜像，见[下载与镜像](./downloads)。

## 5. 下一步

- 了解[独立与共享配置](./versions#独立与共享配置)的取舍
- 学会[备份存档](./saves#备份与恢复)，养成好习惯
- 用[配置编辑器](./config)微调游戏体验（分辨率、自动保存间隔、经济难度…）
