# 常见问题

## Windows 相关

**Q: SmartScreen 提示"已保护你的电脑"？**
A: 启动器尚未代码签名。点击"更多信息 → 仍要运行"。介意的话，可自行从源码构建（见开发文档）或等待后续签名版本。

**Q: 杀毒软件报毒 / 拦截？**
A: 启动器会修改自身目录外的文件（数据根目录）并启动游戏进程，部分杀软会启发式拦截。将启动器目录加入白名单即可；若仍误报，欢迎带诊断包提 Issue。

**Q: 游戏启动后报缺少 DLL？**
A: 官方 OpenTTD 发行包自带所需运行库。若从自定义源安装的版本缺 DLL，安装对应的 VC++ 运行库（vc_redist.x64）。

## Linux 相关

**Q: 启动器打不开，报 GTK/GLib 错误？**
A: Flutter Linux 构建依赖 GTK3：`sudo apt install libgtk-3-0 libblkid1 liblzma5`（Debian/Ubuntu 系；其他发行版对应包名类似）。

**Q: 版本安装失败，解压 `.tar.xz` 出错？**
A: Linux 上启动器调用系统 `tar` 解压 `.tar.xz`，请确认系统已安装 xz（`tar --version` 正常即可）。通常发行版都自带。

## macOS 相关

**Q: "无法打开，因为无法验证开发者"？**
A: 应用尚未签名公证。右键 App → 打开；或执行 `xattr -cr /Applications/OpenDepot.app`。见[安装](./install#macos)。

**Q: 游戏窗口无法全屏 / 分辨率异常？**
A: 先在游戏内 Video Options 调整；或用启动页的 `-r` 参数指定分辨率。

## 下载与网络

**Q: 下载一直失败或很慢？**
A: 依次尝试：① 设置 → 下载与镜像 → 重新测速；② 添加自定义镜像（见[下载与镜像](./downloads#添加自定义镜像)）；③ 策略切为"仅官方源"排查镜像问题。

**Q: 断点续传没有生效，从头下了？**
A: 远端文件变动（长度/ETag 不一致）或镜像不支持 Range 时会重新下载，这是防止拼出损坏文件的保护行为。

**Q: SHA-256 校验失败？**
A: 不要忽视此提示。可能是下载损坏，也可能是镜像被污染。换官方源重试；若官方源也失败，请带日志提 Issue。

## 版本与配置

**Q: 官方版和 JGRPP 的存档互通吗？**
A: 基本互通（存档向后兼容），但用了 JGRPP 特有设置/模组的服务器内容在官方版可能表现不同。跨版本玩存档前先备份。

**Q: 手动装过 OpenTTD，能让启动器接管吗？**
A: 可以，"添加本地版本"指向已有的游戏目录（含可执行文件），启动器会补写清单而不移动文件。

**Q: 配置改坏了，游戏起不来？**
A: 配置编辑器每次保存都有 `.bak` 备份；配置页可恢复。极端情况删除 `openttd.cfg` 让游戏重新生成。

**Q: 游戏自己下载的模组在哪？**
A: 与启动器安装的位置相同（`content_download/` 下的对应子目录），模组中心会一并识别。

## 其他

**Q: 启动器会收集我的数据吗？**
A: 不会。无遥测、无埋点；网络访问只发生在你主动下载/刷新时。

**Q: 支持移动版 / 手机？**
A: 暂无计划，首发仅桌面三平台。

**Q: 找不到答案？**
A: 到 [Discussions](https://github.com/hello-openttd/hello-openttd/discussions) 提问，或按[贡献指南](https://github.com/hello-openttd/hello-openttd/blob/main/CONTRIBUTING.md)提 Issue（附诊断包）。
