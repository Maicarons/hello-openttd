# 外观与语言

设置页管理启动器自身的偏好。

## 语言

- 支持 **简体中文** 与 **English**，默认跟随系统语言（不可识别时回退英文）。
- 切换**即时生效**，无需重启；选择保存在 `settings.json`。
- 未翻译的键回退到英文。

## 主题

| 选项 | 说明 |
|------|------|
| 浅色 | 浅色主题 |
| 深色 | 深色主题 |
| 跟随系统（默认） | 与操作系统深浅色设置同步 |

主题基于 Material 3 构建，深浅色共用同一套品牌色（OpenTTD 绿为主色调）。窗口装饰（标题栏）颜色随主题自动适配。

## 数据根目录

显示当前数据根目录，支持**迁移**（选择新目录后自动搬移版本、共享数据与缓存）与**打开目录**快捷入口。便携模式的目录无法迁移（随程序目录走）。

## 下载与镜像

见 [下载与镜像](./downloads)：策略选择、镜像增删、测速、GitHub 访问令牌。

## 高级

- **日志级别**：info（默认）/ debug / trace
- **打开日志目录**：`logs/` 所在位置
- **诊断包**：把日志与脱敏后的环境信息打包成 zip，便于附在 Issue 里（**不含**令牌与存档内容）
- **重置启动器设置**：仅重置 `settings.json`，不删除版本与存档
- **检查启动器更新**：手动触发（当前版本不做自动后台检查）

## 快捷键

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+1..8` | 切换左侧主导航页面 |
| `Ctrl+,` | 打开设置 |
| `Ctrl+R` | 刷新当前页数据 |
| `F5` | 同上 |
