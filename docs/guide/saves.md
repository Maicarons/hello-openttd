# 存档管理

存档页集中管理当前所选版本（独立模式）或共享目录（共享模式）下的所有存档。

## 浏览与搜索

- 扫描目录：`save/`（含 `save/autosave/` 自动存档）、`scenario/`、`heightmap/`。
- 列表列：文件名、大小、修改时间、来源目录；自动存档分组显示。
- **搜索**：按文件名模糊匹配；**排序**：名称/时间/大小。
- 快捷操作：打开所在目录、重命名、删除（进入系统回收站，可恢复）。

## 元数据

列表信息来自文件系统（名称、时间、大小）。存档内部的**游戏日期 / 公司数 / 存档版本**等深度信息依赖对 `.sav` 格式的解析，计划以"尽力而为"的方式提供（解析失败不影响基础功能）。

## 导入与导出

- **导入**：选择本地 `.sav` / `.scn` 文件复制进当前版本的存档目录；重名时可自动改名（`xxx-1.sav`）或覆盖（需确认）。
- **导出**：把存档复制到任意目录，方便分享给朋友或迁移。
- 支持多选批量操作与 zip 打包导出。

## 备份与恢复

备份解决两个问题：误删 / 存档损坏、跨设备迁移。

**手动备份**：选中存档 → 备份，或整目录一键备份。

**自动备份策略**（设置 → 存档）：

| 选项 | 说明 |
|------|------|
| 触发时机 | 每次启动游戏前 / 每日首次启动 / 仅手动 |
| 保留数量 | 最多保留 N 份（默认 20），超出自动清理最旧的 |
| 存放位置 | `<数据根目录>/shared/backups/` |

**备份格式**：zip 归档，内含存档文件与 `manifest.json`（时间、版本、文件清单与哈希），因此备份可以脱离启动器独立还原。

**恢复**：从备份列表选择 → 恢复到原位置或指定版本；恢复前若目标位置已有同名文件，会先做一次安全备份。

## 迁移建议

- 更换电脑：导出备份 zip + 共享目录中的存档即可完整迁移。
- 版本目录删除不会自动删除备份——备份独立存放，永远多一层保险。
